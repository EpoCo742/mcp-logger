Plain-language glossary

TermWhat it means here
AgentSoftware that uses an AI model to decide which steps to take, then takes them
MCPModel Context Protocol: a standard way for an outside AI agent to call our tools
Enforcement pointA shared gateway every AI call must pass; it applies policy and writes the record
Provenance stampA tag on each returned value: which system, which record, when, and a fingerprint
GroundingLinking each sentence of an answer to the stamped values it relied on
Hash chainEach record carries the fingerprint of the previous one, so edits break the chain
CheckpointA signed, independently timestamped summary of all records up to that moment
Fail closedIf the record cannot be written, the action does not happen
TokenisationReplacing a sensitive value with a stand-in; the original is kept in a sealed vault
