Two paths. The assistant path: the firm's advisor talks to our assistant; the Edge Gateway admits the call, the Agent Runtime plans, the Model Gateway is the only door to an outside model, and the Tool Gateway is the only door to our systems. The direct path: a third party's own agent calls our tools over MCP; it still passes the Edge Gateway and the Tool Gateway. Application teams never log on their own; the four shared points do it.
